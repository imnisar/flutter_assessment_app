# Swéy - Flutter Shop UI Assessment

This project is a high-performance shopping application built for a technical assessment. It focuses on pixel-perfect UI implementation, smooth animations, and clean architecture.

## Key Features
- **Pull-to-Reveal Tags:** Short pull-down gesture to show/hide category shortcuts.
- **Glassmorphism:** Premium frosted-glass effect on Bottom Navigation Bar and Headers.
- **Staggered Product Grid:** Pinterest-style Masonry layout for product discovery.
- **Global Scene Section:** Overlapping flag indicators for global brand discovery.

##  Tech Stack
- **Framework:** Flutter (Latest Version)
- **State Management:** Riverpod (For scalable and testable state)
- **Database:** Isar (High-performance local storage)
- **Architecture:** Feature-first Clean Architecture

##  Quality Check
- **Accessibility:** Tested for 200% text scaling (WCAG AA).
- **Performance:** Optimized for ≤ 2.5s cold start and 60 FPS scrolling.
- **Responsiveness:** Fully responsive across different screen sizes.
